SWIFT 是大语言模型与多模态模型的训练、推理和部署框架。v5 将通用能力下沉到 [twinkle](https://github.com/modelscope/twinkle) 组件库：SWIFT 负责模型和数据适配、配置及算法 recipe，twinkle 提供模型、数据、采样、分布式执行和服务端 / 客户端能力。

设计原则是“写单机代码，训任意规模”。Ray 管理并行执行，命令行和 Python API 共用配置与组件；harness 接入 Agentic RL，Transformers、Megatron 与远程训练复用同一使用接口。ModelScope 服务提供远端模型算力，WebUI 将训练任务、自动研究和工作流编排放在一个工作台中。

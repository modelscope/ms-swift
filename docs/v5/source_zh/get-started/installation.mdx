## Wheel 包安装

### 本地训练

```bash
pip install 'ms-swift>=5.0.0'

# 可选依赖
pip install 'ms-swift[megatron]'  # Megatron 后端：会安装 mcore-bridge，megatron-core；需匹配本机 CUDA 环境，所以不包含在 all 中
pip install 'ms-swift[eval]'  # 可用于评测，会安装 evalscope 及 opencompass / vlmeval 后端

# 使用 uv 安装，并自动选择匹配当前设备的 PyTorch
pip install uv
uv pip install 'ms-swift>=5.0.0' --torch-backend=auto
```

### 部署SaaS化训练服务

<ArchitectureDiagram src="/images/v5/package-dependencies.zh.svg" alt="ms-swift 与 twinkle 的依赖关系" />

在提供 GPU 算力的机器上安装。服务端负责模型，采样器与资源配置，客户端通过它提交训练操作；使用 `swift deploy` 启动服务时需要同机安装 `ms-swift`：

```bash
pip install twinkle-server ms-swift>=5.0.0
```

完整部署步骤见[远程训练与 twinkle-server](../interfaces/server-client.mdx)。

### 客户端远程训练

在提交训练任务的机器上安装，客户端不需要本地 GPU：

```bash
pip install twinkle-client

# swift的`--mode remote`参数可以将训练平滑切换到训练服务上运行，如需使用：
pip install ms-swift>=5.0.0
```

## 源码安装

使用开发分支或需要修改代码时，克隆仓库后在同一个 Python 环境中安装：

```bash
git clone https://github.com/modelscope/ms-swift.git
cd ms-swift
pip install -e .
uv pip install -e . --torch-backend=auto  # 使用 uv
```

## 支持的硬件

| 硬件 | 说明 | 参考 |
|---|---|---|
| NVIDIA GPU | 默认支持；本站示例以 NVIDIA GPU，BF16 为例 | — |
| AMD GPU | 使用 ROCm 版 PyTorch | [AMD GPU 支持](../platforms/amd-support.mdx) |
| 昇腾 NPU | 安装与 CANN 匹配的 torch-npu，并按推理引擎准备昇腾扩展 | [昇腾 NPU 支持](../platforms/npu-support.mdx) |
| 昆仑芯 XPU | 使用昆仑芯提供的 torch_xmlir 与 vLLM 镜像；twinkle 通过 `xpu-smi` 识别，多卡通信使用 BKCL | — |
| 沐曦 MetaX GPU | 使用 MACA 版 PyTorch 与官方预构建镜像 | [沐曦 MetaX 支持](../platforms/metax-support.mdx) |
| 摩尔线程 MUSA GPU | 通过 torch_musa 与 torchada 支持，使用官方训练镜像 | [摩尔线程 MUSA 支持](../platforms/musa-support.mdx) |
| Apple MPS | 可用于兼容模型的本地推理或小规模训练 | [issue](https://github.com/modelscope/ms-swift/issues/4572) |
| CPU | 可用于兼容模型的本地推理或小规模训练 | — |


## 支持的模型框架

前三种由 `--backend` 选择，不填即 transformers；sentence_transformers 没有开关，只在 `embedding` 任务下自动选中。

| 能力 | transformers | megatron | unsloth | sentence_transformers |
|---|---|---|---|---|
| 安装 | — | `pip install 'ms-swift[megatron]'` | `pip install unsloth` | `pip install sentence-transformers` |
| 任务类型 | 全部 | 全部 | `causal_lm` | `embedding` |
| 训练方式 | 全参 / LoRA | 全参 / LoRA | 全参 / LoRA | 全参 / LoRA |
| TP / PP / CP / EP | 部分支持 | 支持 | 不支持 | 不支持 |
| DeepSpeed | 支持 | 不支持 | 不支持 | 不支持 |
| FSDP | 支持 | 支持 | 不支持 | 支持 |
| 量化训练 | 支持 | 不支持 | 仅 BNB | 不支持 |

unsloth 不支持训练中评估。

## 支持的采样器

采样器后端有 `vllm`，`sglang`，`transformers` 三种。下表只列 swift 侧的限制，模型能否运行还取决于引擎本身是否支持。

### 任务类型

| 任务类型 | vllm | sglang | transformers |
|---|---|---|---|
| 文本 / 多模态生成（`causal_lm`） | 支持 | 支持 | 支持 |
| `generative_reranker` | 支持 | 支持 | 支持 |
| `embedding`，`seq_cls`，`reranker` | 支持 | 支持 | 不支持 |
| `decision` | 不支持 | 仅 `kev`，`clef`，不支持 `--adapters` | 不支持 |

### 训练支持

| 能力 | vllm | sglang | transformers |
|---|---|---|---|
| 模型加载量化（`--quant_method`） | 不支持 | 不支持 | 支持 |
| 引擎加载量化（`--vllm_quantization` / `--sglang_quantization`） | 支持 | 支持 | 无 |
| 低精度权重同步 | FP8，部分模型MXFP4 | 不支持 | — |
| LoRA 服务（`--adapters`） | 支持 | 支持 | 支持 |
| 在线 RL rollout 与权重同步 | 支持 | 支持 | 不支持 |
| `delta 同步` | 支持，不含 MoE 与量化模型 | 支持 | 无 |
| `colocate 模式` | 支持，需 `--parameter_sync_step 1` | 同 vllm | 无 |

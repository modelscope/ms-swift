## 镜像来源

SWIFT 镜像由 ModelScope 仓库的 [docker 目录](https://github.com/modelscope/modelscope/tree/master/docker) 构建，`build_image.py` 负责拼接标签，Dockerfile 按平台拆分：`Dockerfile.ubuntu` / `Dockerfile.ubuntu_base` 为 NVIDIA GPU 基础镜像，`Dockerfile.amd`，`ascend/`，`Metax/` 分别对应 AMD，昇腾，沐曦。镜像预装 CUDA，PyTorch，vLLM，ModelScope 与 SWIFT，标签依次包含这些组件的版本。

同一镜像在三个地域的地址如下，选择距离运行环境较近的 registry：

```text
# swift5.0.0
modelscope-registry.cn-hangzhou.cr.aliyuncs.com/modelscope-repo/modelscope:ubuntu22.04-cuda13.0.3-py312-torch2.14.0-vllm0.33.0-modelscope1.40.3-swift5.0.0
modelscope-registry.cn-beijing.cr.aliyuncs.com/modelscope-repo/modelscope:ubuntu22.04-cuda13.0.3-py312-torch2.14.0-vllm0.33.0-modelscope1.40.3-swift5.0.0
modelscope-registry.us-west-1.cr.aliyuncs.com/modelscope-repo/modelscope:ubuntu22.04-cuda13.0.3-py312-torch2.14.0-vllm0.33.0-modelscope1.40.3-swift5.0.0
```

## 启动容器

宿主机应安装 NVIDIA 驱动，Docker 和 NVIDIA Container Toolkit。下面将模型缓存与训练输出挂载到宿主机目录：

```bash
mkdir -p "$HOME/.cache/modelscope" "$PWD/output"
IMAGE=modelscope-registry.cn-hangzhou.cr.aliyuncs.com/modelscope-repo/modelscope:ubuntu22.04-cuda13.0.3-py312-torch2.14.0-vllm0.33.0-modelscope1.40.3-swift5.0.0
docker run --gpus all --ipc=host -it \
    -e MODELSCOPE_CACHE=/cache/modelscope \
    -v "$HOME/.cache/modelscope:/cache/modelscope" \
    -v "$PWD/output:/workspace/output" \
    -w /workspace \
    "$IMAGE" bash
```

镜像已自带 SWIFT 及相关依赖，直接运行[快速启动](./quick-start.mdx)的 SFT 或 GRPO 示例。采样器，数学奖励及其他任务依赖按对应示例安装。

## 主要软件包

| 软件 | 版本 |
|---|---|
| Ubuntu | 22.04 |
| CUDA | >=13.0 |
| Python | >=3.12 |
| PyTorch | >=2.14 |
| Transformers | >=5.12 |
| mcore-bridge | >=1.7 |
| Megatron-Core | >=0.19 |
| TransformerEngine | >=2.16 |
| FlashAttention | >=2.8 |
| flash-linear-attention | >=0.5 |
| vLLM | >=0.20 |
| ModelScope | >=1.40 |
| SWIFT | >=5.0 |
| twinkle（kit / server / client） | >=1.0 |
| Ray | >=2.55 |

AMD，NPU 等平台的设备映射和运行时不同，按[硬件支持](./installation.mdx)中的平台资料准备环境。

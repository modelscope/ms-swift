SWIFT 是大模型训练框架：完整的 recipe、命令行与代码级 API，覆盖微调、人类对齐、
在线 RL、评测、导出与部署。[twinkle](https://github.com/modelscope/twinkle) 是它的
底层组件库——训练/推理组件也可以脱离 SWIFT 单独组合成训练脚本。

<Callout type="info">
这里是 **5.0.0.dev** 开发版文档。v5 尚未发布到 PyPI，请按
[快速启动](./get-started/quick-start.mdx) 从源码安装。
</Callout>

## 设计原则

写单机代码，训任意规模。分布式（Ray）、后端（transformers / Megatron / remote）
与放置都是配置而不是重写：同一份 recipe 可以跑在单卡、单机或集群上。

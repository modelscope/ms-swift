## 安装（开发版本）

v5 正在开发中，尚未发布到 PyPI，请从源码安装：

```bash
git clone https://github.com/modelscope/ms-swift.git
cd ms-swift
pip install -e .
# twinkle（组件库）与 mcore-bridge（Megatron 权重转换）
git clone https://github.com/modelscope/twinkle.git && pip install -e twinkle
git clone https://github.com/modelscope/mcore-bridge.git && pip install -e mcore-bridge
```

环境要求：Python >= 3.10（推荐 3.12），GPU 训练推荐 CUDA 12.8/13.0。
NPU/XPU/CPU 见[环境安装与硬件支持](./installation.mdx)。

## 第一个 LoRA 训练

```bash
CUDA_VISIBLE_DEVICES=0 \
swift sft \
    --model Qwen/Qwen3.5-4B \
    --attn_impl flash_attention_2 \
    --task_type causal_lm \
    --torch_dtype bfloat16 \
    --dataset 'swift/self-cognition#600' \
    --tuner lora \
    --lora_rank 8 --lora_alpha 32 --target_modules all-linear \
    --num_train_epochs 3 \
    --per_device_train_batch_size 1 --gradient_accumulation_steps 8 \
    --learning_rate 1e-4 --lr_scheduler cosine --warmup_ratio 0.05 \
    --max_length 2048 \
    --logging_steps 5 --save_steps 100 --save_total_limit 2 \
    --output_dir output
```

看什么：

- self-cognition 是模型必须新学的知识，`loss` 应明显下降；通用 SFT 数据上
  已 instruct 的模型提升空间小，曲线平缓是正常的。
- checkpoint 每 `--save_steps` 落到 `output/`，`--save_total_limit` 轮转旧存档。
- `--tuner full` 切换全参数训练。

可运行脚本与实测显存标注见
[`examples/v5/train/lora/train.sh`](https://github.com/modelscope/ms-swift/blob/main/examples/v5/train/lora/train.sh)；
同目录 `train.py` 是同一训练的组件级 Python 写法。

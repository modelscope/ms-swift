## 模型

`--model` 接受 hub id（默认 ModelScope，`--use_hf true` 走 Hugging Face）
或本地路径。SWIFT 从注册表解析模型族、模板与任务头——v5 loader 注册了
247 个模型 loader，覆盖 Qwen、DeepSeek、GLM、Gemma、Llama、InternLM、
MiniCPM、多模态与 embedding/reranker 等族（按 `swift/dev/model/loader/` 的
`@register_model` 计数）。

```bash
--model Qwen/Qwen3.5-4B          # 多模态 dense
--model Qwen/Qwen3-30B-A3B       # MoE
--model Qwen/Qwen3.5-4B-Base     # 预训练 / base-to-chat 用 base 权重
```

各模型族示例见
[`examples/v5/models`](https://github.com/modelscope/ms-swift/tree/main/examples/v5/models)。
未注册的模型 id 会直接报不支持的 model type——绝不静默回落到其他族。

## 数据集

`--dataset` 接受 hub 数据集 id、本地 jsonl/csv 文件，以及 `#N` 切片后缀：

```bash
--dataset 'swift/self-cognition#600'              # 前 600 行
--dataset 'AI-MO/NuminaMath-TIR#5000'             # RL prompts
--dataset /path/to/custom.jsonl                   # 本地 messages 格式文件
```

自定义数据遵循 messages 格式（`{"messages": [{"role": ..., "content": ...}]}`）；
任务专用格式（embedding 对、reranker 三元组、偏好对、分类标签）见对应训练页与
[`examples/v5/train/data`](https://github.com/modelscope/ms-swift/tree/main/examples/v5/train/data)。

数据集注册与预处理插件见[代码 API 与插件](../interfaces/code-api.mdx)。

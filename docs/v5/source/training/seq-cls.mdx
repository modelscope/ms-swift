---
title: 分类任务的训练
description: 带任务头的序列分类；单标签/多标签与回归。
---

```bash
swift sft \
    --model Qwen/Qwen3.5-4B \
    --task_type seq_cls \
    --num_labels 2 \
    --problem_type single_label_classification \
    --attn_impl flash_attention_2 --torch_dtype bfloat16 \
    --dataset 'hc3-zh:finance_cls#2000' \
    --tuner full \
    --num_train_epochs 3 --learning_rate 1e-5 \
    --output_dir output
```

- `--num_labels` 决定头宽度；`--problem_type` ∈
  single_label_classification / multi_label_classification / regression。
- 数据：messages 行加 `label` 字段（索引、标签列表或浮点）；
  布局见 `examples/v5/train/data/seq_cls.jsonl`。
- 分类头在骨干之上从头训练——骨干 LoRA + 可训练头是常见的省显存配置。
- 奖励模型训练（`swift rl --rlhf_type rm`）是标量打分的偏好对变体，
  见[人类对齐](../alignment/human-alignment.mdx)。

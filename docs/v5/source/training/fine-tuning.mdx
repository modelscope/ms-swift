## Tuner

| Tuner | 旗标 | 场景 |
|---|---|---|
| LoRA | `--tuner lora --lora_rank 8 --lora_alpha 32 --target_modules all-linear` | 默认；省显存、可合并 |
| 全参 | `--tuner full` | 容量最大，显存更高 |
| Trainable tokens | `--tuner trainable_tokens` | 只训选定 token 的 embedding |

LoRA 变体（DoRA、rsLoRA、QLoRA）是 LoRA 路径上的旗标，不是独立 tuner；
量化旗标在 `QuantizeConfig`。多模态定向：`--freeze_vit/--freeze_aligner/--freeze_llm`
决定 `all-linear` 训练哪些塔（默认训 LLM、冻结 vision + aligner）。

## 效率旗标

- `--gradient_checkpointing true`——以算力换显存。
- `--packing true` / `--padding_free true`——序列打包 / 无 padding 批。
- `--attn_impl flash_attention_2`（Hopper 上可 `flash_attention_3`）——attention 内核。
- `--use_liger_kernel true`——支持处启用 Liger 融合内核。
- 优化器路径：`--optim muon`，或 GaLore `--use_galore true --galore_rank 128`
  （`examples/v5/train/{muon,galore}`）。
- 超大数据集用 `--streaming true`；`--cached_dataset` 跨 run 复用编码 token。

## Checkpoint 与日志

`--save_steps`、`--save_total_limit`、`--output_dir`、`--report_to tensorboard`、
`--logging_steps`；`--resume_from_checkpoint` 续训。每个示例脚本页头记录
该配置的实测峰值显存。

各任务页（embedding、reranker、分类、decision）复用完全相同的旗标面——
只有 `--task_type`、`--loss` 与数据格式不同。

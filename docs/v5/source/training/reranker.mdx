## 交叉编码 reranker

```bash
swift sft \
    --model Qwen/Qwen3.5-4B \
    --task_type reranker \
    --loss pointwise_reranker \
    --attn_impl flash_attention_2 --torch_dtype bfloat16 \
    --dataset 'scidocs-reranking#2000' \
    --tuner full \
    --num_train_epochs 3 --learning_rate 1e-5 \
    --output_dir output
```

- 数据行是带相关性标签的 query/document 对；任务头对每对输出标量分。
  loss 注册表里除 `pointwise_reranker` 外还有 listwise/pairwise 可选。
- 专用 reranker 骨干（如 `BAAI/bge-reranker-base`）走同一命令。
- 数据布局见 `examples/v5/train/data/reranker.jsonl`。

## Generative reranker

`--task_type generative_reranker` 保持模型的生成形态：相关性以文本产出
（如 yes/no 判断），用判断 token 上的语言模型 loss 训练。正/负消息布局与
embedding 相同；希望 reranker 同时保留对话能力时选这条路径。

推理：`swift infer --task_type reranker` 输出分数；生成路径返回判断文本。

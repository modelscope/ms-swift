---
title: Unsloth 模型的训练
description: unsloth 后端复用 transformers 构造，LoRA/全参训练更快更省。
---

`--backend unsloth` 在 transformers 之上选择 Unsloth 优化构造路径——
同一 Config 面、同一 recipe，在 Unsloth 支持的模型族上内核更快、显存更低。

```bash
swift sft \
    --backend unsloth \
    --model Qwen/Qwen3.5-4B \
    --tuner lora --lora_rank 8 --lora_alpha 32 --target_modules all-linear \
    --dataset 'swift/self-cognition#600' \
    --torch_dtype bfloat16 \
    --output_dir output
```

说明：

- 环境里需安装 `unsloth` 包；支持的模型族跟随 Unsloth 自身覆盖面。
- LoRA 与全参训练都走这条路径；分布式旗标（`--mode`、`--nproc_per_node`）不变。
- Unsloth 不支持的族会在构造期直接报错——请切回默认 transformers 后端，
  不要期待静默回落。

---
title: 预训练
description: 用非对话 loss 对 base 模型继续预训练。
---

`swift pt` 就是带非对话 loss 的 SFT：打包文本的每个 token 都承载 loss，
不做对话模板掩码。用 base 权重，不要用 instruct checkpoint。

```bash
swift pt \
    --model Qwen/Qwen3.5-4B-Base \
    --attn_impl flash_attention_2 --torch_dtype bfloat16 \
    --dataset examples/v5/train/data/pretrain.jsonl \
    --tuner full \
    --num_train_epochs 5 --learning_rate 2e-5 --lr_scheduler cosine \
    --per_device_train_batch_size 1 --gradient_accumulation_steps 1 \
    --max_length 2048 --output_dir output
```

- 数据：纯文本行（`{"messages": [{"role": "assistant", "content": "..."}]}`
  或原始文本 jsonl），见 `examples/v5/train/data/pretrain.jsonl`。
- `--packing true` 把短文档打包成满长序列提升吞吐。
- **Base-to-chat**：预训练后在 instruct 数据上 SFT 得到对话模型——
  `examples/v5/train/base_to_chat` 给出两阶段流水线。
- 用 `--mode ray --nproc_per_node N` 扩展，与 SFT 完全一致。

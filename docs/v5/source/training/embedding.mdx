---
title: Embedding 训练
description: InfoNCE 对比训练；sentence-transformers 数据集直接可用。
---

```bash
swift sft \
    --model Qwen/Qwen3.5-4B \
    --task_type embedding \
    --loss infonce \
    --attn_impl flash_attention_2 --torch_dtype bfloat16 \
    --dataset 'stsb:positive#2000' \
    --tuner lora --lora_rank 8 --lora_alpha 32 --target_modules all-linear \
    --num_train_epochs 3 --learning_rate 1e-4 \
    --output_dir output
```

## 数据

- 对比行包含 anchor 与 `positive_messages` / `negative_messages`；
  InfoNCE 预处理器据此构造批内负样本。
- **sentence-transformers 兼容**：sentence-transformers 集合的数据集 id
  （如 `sentence-transformers/stsb`）会被识别并预处理成同一布局——
  示例里的 `stsb:positive` 子集选择器正是这条路径。存量 ST 数据集无需转换即可训练。
- 自定义 jsonl 布局见 `examples/v5/train/data/embedding.jsonl`。

## 说明

- 池化与归一化属于 embedding 头；`swift infer --task_type embedding` 输出向量。
- 专用 embedding 骨干（注册为 embedding 模型的 BGE/GTE 族等）走同一命令。
- 多模态输入见[多模态 Embedding](./multimodal-embedding.mdx)。

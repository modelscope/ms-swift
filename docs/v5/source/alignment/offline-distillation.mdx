## 序列级（离线）蒸馏

最简单的蒸馏不需要专门算法：用强教师生成回复，再让学生在其上 SFT。

1. 用 `swift infer`（或任意教师服务端点）在 prompt 集上产出教师数据，
   存成 messages 格式 jsonl。
2. 训练学生：

```bash
swift sft \
    --model Qwen/Qwen3.5-4B \
    --dataset /path/to/teacher_outputs.jsonl \
    --tuner lora --learning_rate 1e-4 \
    --torch_dtype bfloat16 --attn_impl flash_attention_2 \
    --output_dir output
```

这就是普通 SFT——知识转移发生在数据里。教师明显更强、prompt 固定时，
这是正确的起点。

## On-policy 蒸馏

学生必须从**自己的**采样对照教师学习时，走在线路径（有 rollout，属 RL 族）：

- `swift rl --rlhf_type gkd --teacher_model <教师>`——学生 rollout 上的
  广义知识蒸馏。
- `swift rl --rlhf_type opsd --teacher_model <教师> --external_plugins <插件>`——
  插件定义目标的 on-policy 自蒸馏。
- `swift rl --rlhf_type mopd`——多教师 on-policy 蒸馏。

见[在线学习](./online-rl.mdx)与 `examples/v5/rl/{gkd,opsd,mopd}`。

---
title: Embedding Training
description: InfoNCE contrastive training; sentence-transformers datasets work directly.
---

```bash
swift sft \
    --model Qwen/Qwen3.5-4B \
    --task_type embedding \
    --loss infonce \
    --attn_impl flash_attention_2 --torch_dtype bfloat16 \
    --dataset 'stsb:positive#2000' \
    --tuner lora --lora_rank 8 --lora_alpha 32 --target_modules all-linear \
    --num_train_epochs 3 --learning_rate 1e-4 \
    --output_dir output
```

## Data

- Contrastive rows carry an anchor plus `positive_messages` / `negative_messages`;
  the InfoNCE preprocessor builds in-batch negatives from them.
- **sentence-transformers compatibility**: dataset ids from the
  sentence-transformers collection (e.g. `sentence-transformers/stsb`) are
  recognized and preprocessed into the same layout — the `stsb:positive` subset
  selector in the example is exactly this path. Existing ST datasets train
  without conversion.
- Custom jsonl layout: `examples/v5/train/data/embedding.jsonl`.

## Notes

- Pooling and normalization are part of the embedding head; inference returns
  vectors via `swift infer --task_type embedding`.
- Dedicated embedding backbones (e.g. BGE/GTE family models registered as
  embedding models) train through the same command.
- Multimodal inputs: see [Multimodal Embedding](./multimodal-embedding.mdx).

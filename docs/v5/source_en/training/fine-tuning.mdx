## Tuners

| Tuner | Flag | When |
|---|---|---|
| LoRA | `--tuner lora --lora_rank 8 --lora_alpha 32 --target_modules all-linear` | default; cheap, mergeable |
| Full | `--tuner full` | maximum capacity, more VRAM |
| Trainable tokens | `--tuner trainable_tokens` | train only selected token embeddings |

LoRA variants (DoRA, rsLoRA, QLoRA) are flags on the LoRA path, not separate
tuners; quantization knobs live in `QuantizeConfig`. Multimodal targeting:
`--freeze_vit/--freeze_aligner/--freeze_llm` choose which towers `all-linear`
touches (defaults train the LLM, freeze vision + aligner).

## Efficiency knobs

- `--gradient_checkpointing true` — trade compute for memory.
- `--packing true` / `--padding_free true` — sequence packing / padding-free batches.
- `--attn_impl flash_attention_2` (or `flash_attention_3` on Hopper) — attention kernel.
- `--use_liger_kernel true` — Liger fused kernels where supported.
- Optimizer paths: `--optim muon`, or GaLore via `--use_galore true --galore_rank 128`
  (`examples/v5/train/{muon,galore}`).
- `--streaming true` for datasets too large to materialize;
  `--cached_dataset` reuses encoded tokens across runs.

## Checkpoints & logging

`--save_steps`, `--save_total_limit`, `--output_dir`, `--report_to tensorboard`,
`--logging_steps`. Resume with `--resume_from_checkpoint`. Every example script
header records measured peak VRAM for its configuration.

All task-specific pages (embedding, reranker, classification, decision) reuse
this exact knob surface — only `--task_type`, `--loss` and the data format change.

---
title: Multimodal Embedding
description: Image/text/video rows into one vector space with the same InfoNCE path.
---

Multimodal embedding uses the **same command and loss** as text embedding —
only the data carries media:

```bash
swift sft \
    --model Qwen/Qwen3.5-4B \
    --task_type embedding --loss infonce \
    --attn_impl flash_attention_2 --torch_dtype bfloat16 \
    --dataset examples/v5/train/data/vl_embedding.jsonl \
    --tuner lora --lora_rank 8 --lora_alpha 32 --target_modules all-linear \
    --output_dir output
```

- Rows put images/video references inside messages content; the multimodal
  processor of the chosen model family encodes them before pooling.
- The model must be a multimodal family (e.g. Qwen3.5-VL class models); the
  vision tower freeze knobs (`--freeze_vit`, `--freeze_aligner`) apply as usual.
- Data layout: `examples/v5/train/data/vl_embedding.jsonl`; runnable reference
  `examples/v5/train/multimodal_embedding`.
- Dedicated multimodal embedding models (e.g. WeMM-Embedding, EmbeddingGemma
  family) are registered and train through the same surface.

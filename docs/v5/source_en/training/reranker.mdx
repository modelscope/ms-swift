---
title: Reranker & Generative Reranker
description: Pointwise cross-encoder scoring, or generation-based relevance judgment.
---

## Cross-encoder reranker

```bash
swift sft \
    --model Qwen/Qwen3.5-4B \
    --task_type reranker \
    --loss pointwise_reranker \
    --attn_impl flash_attention_2 --torch_dtype bfloat16 \
    --dataset 'scidocs-reranking#2000' \
    --tuner full \
    --num_train_epochs 3 --learning_rate 1e-5 \
    --output_dir output
```

- Rows are query/document pairs with relevance labels; the head outputs a
  scalar score per pair. Listwise/pairwise losses are available in the loss
  registry alongside `pointwise_reranker`.
- Dedicated reranker backbones (e.g. `BAAI/bge-reranker-base`) train through
  the same command.
- Data layout: `examples/v5/train/data/reranker.jsonl`.

## Generative reranker

`--task_type generative_reranker` keeps the model generative: relevance is
produced as text (e.g. yes/no judgments) and trained with the language-model
loss over the judgment tokens. Same positive/negative message layout as
embedding; choose this when you want the reranker to stay a chat-capable LM.

Inference for both: `swift infer --task_type reranker` (scores) or the
generative path returns judgments.

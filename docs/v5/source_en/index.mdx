SWIFT trains, serves and deploys language and multimodal models. v5 moves common capabilities into [twinkle](https://github.com/modelscope/twinkle): SWIFT owns model / data adaptation, configuration and algorithm recipes; twinkle supplies models, data, sampling, distributed execution and server / client capabilities.

The design principle is “write single-machine code, train at any scale.” Ray manages distributed execution; CLI and Python APIs share configuration and components. Harnesses integrate with Agentic RL, while Transformers, Megatron and remote training reuse the same interface. ModelScope services provide remote model compute, and WebUI combines tasks, automated research and workflow orchestration.
